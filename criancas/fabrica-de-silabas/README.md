# Fábrica de Sílabas

Um jogo de Língua Portuguesa para a alfabetização: a criança vê o desenho, toca nas sílabas na ordem e monta a palavra, com a família do B (BA, BE, BI, BO, BU). É um dos jogos de exemplo por matéria, para a professora ver como pode ficar um jogo da sua disciplina antes de criar o dela com o Gemini.

| Campo        | Valor                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------- |
| Público      | Crianças de 6 e 7 anos (1º ano), em três fases: duas sílabas, três sílabas e qual sílaba falta          |
| Projeto      | GamificaEdu, como exemplo para a Oficina de Prompts                                                     |
| O que ensina | Que as palavras são formadas por sílabas: juntar sílabas para formar palavras e achar a sílaba que falta |
| Como usar    | Projetor, com a turma batendo uma palma por sílaba, ou celular e tablet, em dupla                       |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/criancas/fabrica-de-silabas/                       |
| Autoria      | Arthur Medeiros e Paulo Severo                                                                          |

As palavras usam letra bastão maiúscula. O botão "Ouvir a palavra" usa a voz do próprio aparelho e some quando o navegador não tem voz.

Embaixo do jogo, a parte "Para usar na aula" traz o que a turma aprende, como jogar com a turma e as duas mensagens para pedir um jogo parecido no Canvas do Gemini, no método da Oficina de Prompts.

Nada do que a criança faz sai do navegador. O jogo só guarda, no próprio aparelho, se o som está ligado.
