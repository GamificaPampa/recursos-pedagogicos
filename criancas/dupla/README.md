# Programação em Dupla

Uma criança é o piloto e monta o caminho do robô. A outra é o navegador: vê os bugs escondidos e guia o piloto.

| Campo        | Valor                                                                                                                                               |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Público      | Crianças a partir de 7 anos, em duplas, em três níveis (Fácil, Normal e Desafio)                                                                    |
| Projeto      | Curso de Engenharia de Software da UNIPAMPA, Campus Alegrete                                                                                        |
| O que ensina | Programação em dupla: duas pessoas trabalham no mesmo programa, uma escreve e a outra revisa e orienta                                              |
| Como usar    | O piloto joga no celular, no tablet ou no projetor. O navegador lê o QR code da tela para ver os bugs no próprio celular, ou usa os mapas impressos |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/criancas/dupla/                                                                                |
| Autoria      | Arthur Medeiros                                                                                                                                     |

Os mapas do navegador, para quando as crianças não usam celular, estão em [mapas.html](mapas.html) e [mapas.pdf](mapas.pdf).
