# Reta do Bit

Um jogo de Matemática para o ensino médio: o estudante lê a lei de uma reta no gráfico, ajusta o a e o b de y = ax + b até a reta passar por duas estrelas e monta a função de situações do dia a dia. É um dos jogos de exemplo por matéria, para o professor ver como pode ficar um jogo da sua disciplina antes de criar o dele com o Gemini.

| Campo        | Valor                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------- |
| Público      | Estudantes do 1º ano do ensino médio, em três fases: ler o gráfico, acertar as estrelas e do problema à função            |
| Projeto      | GamificaEdu, como exemplo para a Oficina de Prompts                                                                       |
| O que ensina | Função afim: o b é onde a reta corta o eixo y, o a é quanto o y muda quando o x anda 1, e o sinal do a diz se ela sobe ou desce |
| Como usar    | Projetor, com a turma votando na lei ou no a e no b antes do toque, ou celular, com cada estudante jogando                |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/criancas/reta-do-bit/                                                |
| Autoria      | Arthur Medeiros e Paulo Severo                                                                                            |

Na fase 2, o Bit corre pela reta e pega as estrelas que estão nela; se faltar uma, ele diz em que altura a reta passou e onde a estrela estava. Na fase 3, as situações são uma corrida de aplicativo, a bateria do celular, um plano de internet, uma vela e uma caixa d'água, e cada acerto mostra no gráfico uma previsão feita com a função. Embaixo do jogo, a parte "Para usar na aula" traz o que a turma aprende, como jogar com a turma e as duas mensagens para pedir um jogo parecido no Canvas do Gemini.

Nada do que o estudante faz sai do navegador. O jogo só guarda, no próprio aparelho, se o som está ligado.
