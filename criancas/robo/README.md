# Robô pega a estrela

Com setas, a criança monta o caminho do robô até a estrela e aperta para ele andar.

| Campo        | Valor                                                                                   |
| ------------ | --------------------------------------------------------------------------------------- |
| Público      | Crianças a partir de 6 anos                                                             |
| Projeto      | Curso de Engenharia de Software da UNIPAMPA, Campus Alegrete                            |
| O que ensina | Algoritmo: um programa é uma sequência de passos, e a ordem dos passos muda o resultado |
| Como usar    | Celular, tablet ou projetor. No projetor, a turma joga junto, uma jogada por criança    |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/criancas/robo/                     |
| Autoria      | Paulo Severo ([paulosevero/robo-estrela](https://github.com/paulosevero/robo-estrela))  |
