# Ninja dos Bugs

Deslizando o dedo, a criança corta os bugs que aparecem na tela, sem cortar o robô.

| Campo        | Valor                                                                           |
| ------------ | ------------------------------------------------------------------------------- |
| Público      | Crianças a partir de 6 anos, em três níveis (Fácil, Normal e Desafio)           |
| Projeto      | Curso de Engenharia de Software da UNIPAMPA, Campus Alegrete                    |
| O que ensina | Depuração: achar e tirar os erros de um programa sem estragar o que já funciona |
| Como usar    | Celular ou tablet, deslizando o dedo na tela                                    |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/criancas/ninja/            |
| Autoria      | Arthur Medeiros                                                                 |

No projetor, aperte P (ou abra com ?professor no fim do endereço) para escolher a fase, mostrar a resposta e pausar.
