# Pizzaria das Frações

Um jogo de Matemática: a criança lê o pedido de um cliente, como 1/4 da pizza, toca nos pedaços certos e entrega. É um dos jogos de exemplo por matéria, para a professora ver como pode ficar um jogo da sua disciplina antes de criar o dela com o Gemini.

| Campo        | Valor                                                                                                  |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| Público      | Crianças de 9 e 10 anos (4º ano), em três fases: metades e quartos, terços e mesma quantidade          |
| Projeto      | GamificaEdu, como exemplo para a Oficina de Prompts                                                    |
| O que ensina | Frações como partes iguais de um inteiro (metade, terço e quarto) e frações equivalentes (2/4 = 1/2)   |
| Como usar    | Projetor, com a turma decidindo junto, ou celular, com cada criança jogando                            |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/criancas/pizzaria-das-fracoes/                    |
| Autoria      | Arthur Medeiros e Paulo Severo                                                                         |

Embaixo do jogo, a parte "Para usar na aula" traz o que a turma aprende, como jogar com a turma e as duas mensagens para pedir um jogo parecido no Canvas do Gemini, no método da Oficina de Prompts: primeiro a ideia curta, depois os detalhes.

Nada do que a criança faz sai do navegador. O jogo só guarda, no próprio aparelho, se o som está ligado.
