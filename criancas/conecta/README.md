# Conecta o Sistema

A criança liga celulares, servidor e banco de dados com cabos e vê os dados correrem pelo sistema até a foto chegar no celular.

| Campo        | Valor                                                                                                  |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| Público      | Crianças a partir de 8 anos, em três níveis (Fácil, Normal e Desafio)                                  |
| Projeto      | Curso de Engenharia de Software da UNIPAMPA, Campus Alegrete                                           |
| O que ensina | Sistemas: um app é um conjunto de partes ligadas (celular, servidor e banco de dados) que trocam dados |
| Como usar    | Celular, tablet ou projetor, arrastando os cabos                                                       |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/criancas/conecta/                                 |
| Autoria      | Arthur Medeiros                                                                                        |
