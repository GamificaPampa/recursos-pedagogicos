# Recursos pedagógicos

Jogos e materiais que o GamificaPampa leva para as escolas públicas de Alegrete/RS. Tudo é publicado pelo GitHub Pages em [gamificapampa.github.io/recursos-pedagogicos](https://gamificapampa.github.io/recursos-pedagogicos/), e o menu para projetar na sala está em [gamificapampa.github.io/turma](https://gamificapampa.github.io/turma/).

## Para crianças

Jogos de Engenharia de Software para crianças de 6 a 14 anos. Funcionam no celular, no tablet e no projetor.

| Jogo                                                   | Idade | Pasta                                      |
| ------------------------------------------------------ | ----- | ------------------------------------------ |
| Robô pega a estrela                                    | 6+    | [criancas/robo](criancas/robo)             |
| Ninja dos Bugs                                         | 6+    | [criancas/ninja](criancas/ninja)           |
| Programação em Dupla, com os mapas para imprimir       | 7+    | [criancas/dupla](criancas/dupla)           |
| Conecta o Sistema                                      | 8+    | [criancas/conecta](criancas/conecta)       |
| Arcade do Código, três jogos com placar                | Todas | [criancas/arcade](criancas/arcade)         |
| Caça aos Bugs!, com tela de estande                    | Não informada | [criancas/caca-bugs](criancas/caca-bugs)   |
| Missão Dev, com tela de estande para feira de ciências | Não informada | [criancas/missao-dev](criancas/missao-dev) |

## Como adicionar um recurso

Cada jogo ou material ganha uma pasta própria dentro de `criancas/` ou `professores/`, com um `index.html` e um `README.md` que diz o que é, para quem é e de qual projeto veio. Logos, fontes e cores vêm do repositório [identidade-visual](https://github.com/GamificaPampa/identidade-visual), pelo caminho `/identidade-visual/`.
