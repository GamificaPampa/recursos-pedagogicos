# Medalhas do Bit

Medalhas para imprimir, recortar e entregar na hora da conquista. O professor escolhe quantas de cada medalha quer, e a página monta folhas A4 com 12 medalhas de 6 cm, coloridas ou em preto e branco.

| Campo        | Valor                                                                                         |
| ------------ | --------------------------------------------------------------------------------------------- |
| Público      | Professores da Educação Básica, para turmas de 6 a 14 anos                                    |
| Projeto      | GamificaEdu                                                                                   |
| O que ensina | Recompensa de gamificação: cada medalha nomeia uma atitude de quem programa, inclusive errar e tentar de novo |
| Como usar    | Impresso: escolher as medalhas no computador, imprimir em A4, recortar e entregar             |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/professores/medalhas/                     |
| Autoria      | Arthur Medeiros, com o mascote Bit do identidade-visual                                       |

As medalhas usam as poses do Bit de `/identidade-visual/mascote/`. Para trocar o nome, a frase ou a cor de uma medalha, mude a lista `medalhas` no fim do `index.html`. Nenhuma medalha traz nome de criança: há só uma linha em branco para escrever à mão.
