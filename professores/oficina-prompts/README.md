# Oficina de Prompts para professores

Formação em quatro encontros para professores da Educação Básica criarem atividades, histórias e jogos com o Gemini. A página inicial é [index.html](index.html).

| Para              | Arquivos                                                                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quem participa    | `curso.html` (curso online com teste final), `passo-a-passo.html`, `jogo.html` (Jogo do Prompt), `construtor.html`, `biblioteca.html`, `gems.html`, `guia.html` e `guia.pdf`, `galeria.html` |
| Quem dá a oficina | `encontro-1.html` a `encontro-4.html` (slides), `roteiro-formador`, `caderno`, `avaliacao`, `certificado`, `convite`, `proposta` (cada um em `.html` e `.pdf`)                               |

A avaliação pelo celular é um formulário no Google Forms, ligado pelos QR codes dos encontros. As respostas ficam no Forms e não entram neste repositório.
