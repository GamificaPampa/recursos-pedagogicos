# Tudo para imprimir

Junta num lugar só tudo o que o GamificaPampa tem para imprimir, com o número de folhas e o tamanho de cada PDF.

| Campo        | Valor                                                                    |
| ------------ | ------------------------------------------------------------------------ |
| Público      | Professores da Educação Básica                                           |
| Projeto      | Educador 5.0 e GamificaEdu                                               |
| O que ensina | Onde está cada material de papel e quanto ele ocupa                      |
| Como usar    | Celular ou computador, para abrir e imprimir cada PDF                    |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/professores/imprimir/ |
| Autoria      | Arthur Medeiros                                                          |

Os cartões são HTML fixo. Quando um PDF mudar de número de folhas ou de tamanho, ou quando entrar um material novo para imprimir, atualize o cartão dele no `index.html`. O que só quem conduz a formação usa (caderno, avaliação em papel, certificado da oficina) fica no repositório `equipe` e não entra aqui.
