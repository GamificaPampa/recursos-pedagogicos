# Kit de sala

Ferramentas para o projetor na hora da aula: cronômetro com tempos prontos e aviso sonoro, grupos sorteados pelo número da chamada, sorteio de quem responde (sem repetir até todos saírem) e a placa do combinado (pode conversar, falem baixo, silêncio).

| Campo        | Valor                                                                         |
| ------------ | ----------------------------------------------------------------------------- |
| Público      | Professores da Educação Básica                                                |
| Projeto      | GamificaEdu                                                                   |
| O que ensina | Organizar o tempo e os grupos da aula, à vista da turma                       |
| Como usar    | Projetor ou computador da sala, de preferência em tela cheia                  |
| Endereço     | https://gamificapampa.github.io/recursos-pedagogicos/professores/kit-de-sala/ |
| Autoria      | Arthur Medeiros                                                               |

Nada de nome de estudante entra na página: os grupos e o sorteio usam só o número da chamada, e nada é guardado nem enviado. O cronômetro conta pelo relógio do aparelho, então não atrasa se a aba ficar escondida.
